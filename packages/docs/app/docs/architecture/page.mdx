# Architecture

gruffed is a module-graph linter. It builds a graph, analyzes the immutable graph, then reports findings.

## Flow

```text
source files -> gruffed-builder -> Graph -> gruffed-analyzer -> Report -> reporter
```

The phases are intentionally separate:

- `gruffed-builder` creates the graph and build warnings.
- `gruffed-analyzer` consumes `&Graph` and warnings without mutating the graph.
- Reporters consume `&Report` and `&Graph`.

## Design constraints

Graph analysis must scale to large repositories. The core uses typed IDs, adjacency indexes, path interning, and Rust-owned graph memory. The Node binding remains a shim around Rust computation.

Config enables built-in rules. It does not contain custom rule logic, and gruffed does not auto-fix findings.
