# Config

gruffed uses JSONC so config files can contain comments. The CLI auto-discovers `gruffed.jsonc` or `gruffed.json` from the analyzed root unless `--config` is provided.

## Example

```jsonc
{
  "root": "./src",
  "entrypoints": ["src/index.ts"],
  "exclude": ["**/*.test.ts", "node_modules/**"],
  "extensions": [".ts", ".tsx", ".js", ".jsx", ".mjs", ".cjs"],
  "rules": {
    "no-cycles": "error",
    "no-unresolved": "error",
    "no-long-chains": ["warning", { "max": 10 }]
  }
}
```

## Rule settings

Rule settings follow an ESLint-like shape:

```jsonc
{
  "rules": {
    "no-cycles": "error",
    "no-unresolved": "warning",
    "no-long-chains": ["warning", { "max": 8 }],
    "unused-rule": "off"
  }
}
```

Unknown rule names are ignored. Rules are disabled unless explicitly enabled.

## Defaults

The default extensions are:

```json
[".ts", ".tsx", ".js", ".jsx", ".mjs", ".cjs"]
```

No entrypoints and no rules are enabled by default. That makes a missing config safe, but it also means the analyzer will report no rule findings until a `rules` block is added.
