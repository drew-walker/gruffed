# no-unresolved

`no-unresolved` reports relative imports that the builder could not resolve to a source file.

## What it catches

```ts
import { thing } from "./missing";
```

If `./missing` cannot be resolved using the configured extensions and root, the builder records a warning. The analyzer turns that warning into a rule finding when `no-unresolved` is enabled.

## Configuration

```jsonc
{
  "rules": {
    "no-unresolved": "error"
  }
}
```

## Output

```text
error  no-unresolved
       Cannot resolve import "./missing" in src/index.ts:1
```

The finding includes the source file and line number reported by the parser.

## Notes

This rule checks source-file resolution, not package installation health, TypeScript declarations, or framework assets. Bare package imports, Node builtins, unresolved path aliases, and explicit imports of unsupported file types are ignored until package, TypeScript project graph, and framework-file support lands.
