# CLI

gruffed analyzes a JavaScript or TypeScript source tree, builds a module graph, runs enabled rules, and writes a terminal, JSON, or shareable trace report.

## Command

```bash
gruffed --root ./src
```

By default, gruffed looks for `gruffed.jsonc` or `gruffed.json` in the root it is analyzing. If no config file is found, it uses defaults and no rules are enabled.

## Terminal output

```text
gruffed v0.1.0 - module graph analysis

  Nodes:     42    Edges:     61    Build: 7ms    Analyze: 1ms

  error  no-cycles
         Circular dependency detected (3 nodes in cycle): src/a.ts -> src/b.ts -> src/c.ts
```

Terminal output is intended for humans during local development. It groups findings by rule and includes graph statistics and measured build/analyze time.

## JSON output

```bash
gruffed --root ./src --format json
```

JSON output serializes the report shape from `gruffed-core`: findings plus graph stats. It is the preferred format for CI, dashboards, and automation.

## Trace output

```bash
gruffed --root ./src --format trace --trace-max-nodes 80 > graph-trace.json
```

Trace output is a bounded, deterministic projection for sharing and visualization. It adaptively groups the complete Rust-owned graph into directory and file clusters, aggregates imports between clusters, and includes finding paths. The complete module graph remains in Rust memory; the trace contains only the requested projection.

## Exit codes

gruffed exits successfully when no enabled rule reports an error. It exits with failure if any finding has `error` severity or if configuration, root resolution, graph building, or report formatting fails.
